# Flowlyra Support

Flowlyra is currently in early development.

## Bug reports

If something is behaving incorrectly, use the **Bug report** issue form.

Before opening a report:

1. Search existing issues.
2. Reduce the problem to the smallest reproducible example you can.
3. Remove secrets and private source code from logs or screenshots.

## Feature ideas

Use the **Feature request** form for product ideas.

If you're requesting support for a specific language or framework, use the **Framework support** form instead.

## Contribution questions

Read [CONTRIBUTING.md](CONTRIBUTING.md) first.

If the answer is not there, opening a discussion or issue is fine while the project is still young.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
